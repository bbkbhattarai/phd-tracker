Research sources

Monitored sources span the UK, Europe, Canada, Australia, New Zealand, Hong Kong, Asia and the USA. General programme directories are references, not claimed open vacancies. Sources include the AUDITORY list, founded at McGill University. Workshops and conference announcements are excluded from PhD results.

Custom sources are stored locally. For scheduled server-side monitoring, add the same source to scripts/sources.json in GitHub and provide a matching extractor.

Preferences & backups

Applications, notes, seen flags and custom sources are stored in this browser. They do not sync across devices.

Important

A browser can alert you while this app is open. Closed-app push reminders require additional infrastructure. Make regular backups; clearing browser storage can erase local records.

Data migration

Importing a backup from an older PhD Radar version attempts to preserve saved items and application states, but the format has changed. Export the existing app before replacing it.
